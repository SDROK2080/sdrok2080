Practical Workflow

Installation → Run, in VS Code

  1. Install Python
    Go to python.org/downloads, download the latest version, and run the installer. Tick Add python.exe to PATH before clicking Install.
  2. Install VS Code
    Go to code.visualstudio.com, download for your OS, and install it with the default options.
  3. Add the Python extension
    Open VS Code → Extensions icon (Ctrl+Shift+X) → search "Python" (by Microsoft) → click Install.
  4. Select your interpreter
    Press Ctrl+Shift+P → type "Python: Select Interpreter" → choose the Python version you installed.
  5. Create your first file
    File → New File → save it as hello.py in a folder you'll reuse for every topic.
  6. Write and run code
    Type print("Hello, World!") then click the ▷ Run button top-right, or press Ctrl+F5.
  7. Read the output
    Results appear in the Integrated Terminal panel at the bottom — that's the same terminal you'll use for every level.
  8. Install a library
    Open the terminal (Ctrl+`) and run pip install numpy pandas matplotlib — swap in whatever library the current topic needs.
  9. Debug when stuck
    Click just left of a line number to set a breakpoint, then press F5 to step through your code line by line.
