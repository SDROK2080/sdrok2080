The Developer Prompt Framework
Module 3 · 8-part structure for production-quality prompts
R
ROLE

Assign an expert persona. "Act as a senior frontend developer with 10 years of React experience."

P
PROJECT CONTEXT

Describe what you're building, who uses it, and the business goal.

T
TASK

State the specific, bounded deliverable clearly and without ambiguity.

TR
TECHNICAL REQUIREMENTS

List technology stack, versions, APIs, constraints like "vanilla JS only".

C
CONSTRAINTS

What NOT to do: "No jQuery", "No external fonts", "WCAG 2.1 AA compliance".

IO
INPUT / OUTPUT

Specify exact output format: "Separate .html, .css, .js files with folder structure explained."

E
EXAMPLES

Provide a sample input/output or reference a design pattern to follow.

Q
TESTING REQUIREMENTS

"Include 5 test cases covering edge cases, empty input, and invalid formats."

Example: Full Framework in Action
ROLE: Act as a senior frontend developer. PROJECT: Create a responsive student registration webpage. TECHNOLOGY: HTML5, CSS3, and vanilla JavaScript only. REQUIREMENTS: 1. Registration form with full name, email, student ID, program. 2. Validate all required fields on submit. 3. Validate email format with regex. 4. Display clear, accessible validation messages. 5. Fully responsive (desktop, tablet, mobile). 6. No external frameworks or libraries. OUTPUT: Separate HTML, CSS, and JS files. Explain folder structure. Include test cases. TESTING: Provide 5 test cases covering valid/invalid inputs.

4
REST API Layer

5
React Frontend

Build the student dashboard, course viewer, assignment uploader, and grade viewer as React components with Hooks.

6
Testing, Security & Deployment

Generate Jest test suites, security checklist (OWASP Top 10), and a CI/CD pipeline config for GitHub Actions + Vercel.
