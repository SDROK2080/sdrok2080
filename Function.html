The idea

A function f: A → B assigns to every x in the domain A exactly one value f(x) in B. The set of outputs actually produced is the range. Graphically, a vertical line meets the graph at most once (vertical line test). A function is one-to-one if different inputs give different outputs (horizontal line test). Here every curve is built as f(x) = a·g(x − h) + k: a stretches/flips, h shifts right, k shifts up.

Try this

  1. Choose √x, then slide h. Watch the domain start move with it. What is the domain when h = 3?
  2. Choose 1/x. Slide x toward h. What happens to f(x), and why is x = h excluded?
  3. Choose x², switch on the horizontal line test and move c. For which c are there 2 hits, 1 hit, 0 hits? What does that say about one-to-one?
  4. Choose sin x and change a and k. Predict the range before reading it.
  5. With x² keep h = 0, k = 0: is it even or odd? Now set h = 1. What changes?
