Software & Technology

IT Tools Used in POM

Free software and online tools to solve Linear Programming, Transportation, Assignment, Inventory, and Quality Control problems computationally.

📊
Microsoft Excel + Solver
Built-in Excel add-in for solving LP, Transportation, and Assignment problems. Configure objective functions, constraints, and decision variables.
▶ Excel Solver Tutorial →
🔧
TORA (Operations Research)
Menu-driven Windows software for LP, Transportation, Assignment, Network models, CPM/PERT, and Queuing. Runs in automated or tutorial mode.
📄 TORA Guide (PDF) →
🖥️
POM-QM for Windows
Comprehensive teaching tool for OM & quantitative methods. Covers LP, Forecasting, Inventory, Queuing, PERT/CPM, Decision Analysis, and Quality Control.
⬇ Download Info →
📈
Minitab Statistical Software
Industry-standard tool for Statistical Process Control (SPC), Control Charts (X-bar, R, p, c), Process Capability Analysis, and Six Sigma projects.
▶ Minitab Control Charts →
🌐
Online Simplex Calculator
Free browser-based simplex method solver. Enter LP constraints and objective function to get step-by-step tableau solutions with sensitivity analysis.
🌐 Open Calculator →
📐
QM for Windows
Mathematical analyzer for Management Science. Features PERT/CPM, Linear Programming, Decision Analysis, Transportation, Statistical functions, and Game Theory.
⬇ Download Info →

Assessment

Examination Structure

MGT 515 Production & Operations Management: 30 marks internal assessment + 70 marks final written exam = 100 full marks. Minimum pass: 40.

ComponentMarksDetails
Internal Assessment30Presentations, mid-term tests, assignments, case analysis
Final Written Exam70TU Office of the Controller — long questions, numerical problems, case studies
Total100Pass Marks: 40 (Internal + Final combined)
