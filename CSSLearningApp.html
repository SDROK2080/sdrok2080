Phase by Phase

21 CSS Phases — Learn, Then Build

Each phase introduces one CSS concept, then applies it immediately to a component of the Smart Education App.

Phase01
Prepare the CSS Environment
Link your stylesheet; write your first CSS rule; understand syntax, properties, values and comments.
Foundation
Learn
  • CSS file structure
  • CSS rules: selector + declaration
  • Properties and values
  • Comments in CSS
  • Linking CSS to HTML via <link>
Build
  • smart-education-app/ folder
  • css/style.css connected
  • Basic body + heading rules
  • Font-family & font-size set
/* Phase 1 — First CSS */
body {
    font-family: Arial, sans-serif;
    margin: 0;
}
h1 {
    font-size: 2rem;
}
Phase02
Learn CSS Selectors
Element, class, ID, descendant, multiple — then apply to the app's course cards.
Foundation
Selectors
  • Element selector: body { }
  • Class selector: .card { }
  • ID selector: #dashboard { }
  • Multiple: h1, h2, h3 { }
  • Descendant: .card p { }
Build
  • 5 course cards: HTML, CSS, JS
  • Python, Research Methodology
  • .course-card class applied
  • Padding & spacing set
/* Selector types */
body {}  /* element */
.card {}  /* class */
#dashboard {}  /* ID */
h1, h2, h3 {}  /* multiple */
.card p {}  /* descendant */

.course-card { padding: 20px; }
Phase03
Typography
Font families, sizes, weights, line-height, letter-spacing — create a readable lesson page.
Foundation
Learn
  • font-family — typeface selection
  • font-size — rem, px, em
  • font-weight — 300 to 900
  • line-height — readability
  • letter-spacing, text-align
  • text-decoration
Build
  • SMART EDUCATION branded headline
  • Readable lesson body text
  • Sub-headings with correct weights
  • Learning Objectives section
.app-title {
    font-size: 2rem;
    font-weight: 700;
    letter-spacing: -0.02em;
}
.lesson-text {
    line-height: 1.7;
    font-size: 1rem;
}
Phase04
Colors & CSS Custom Properties
Design system foundations — CSS variables for a consistent, maintainable color palette.
Design System
Learn
  • :root { } — global scope
  • --variable-name: value
  • var(--variable-name)
  • Design consistency principle
  • One variable → whole app updates
Build
  • Primary, secondary, background vars
  • Surface & text color tokens
  • Apply to body, buttons, cards
  • Change theme with one edit
:root {
    --primary:    #2563eb;
    --secondary:  #7c3aed;
    --background: #f8fafc;
    --surface:    #ffffff;
    --text:       #1e293b;
    --muted:      #64748b;
}
button { background: var(--primary); }
Phase05
Master the CSS Box Model
Content → Padding → Border → Margin. The rule that governs all layout.
Layout Core
Learn
  • width, height — content size
  • padding — inner spacing
  • border — edge line
  • margin — outer spacing
  • box-sizing: border-box ← always!
Build
  • Professional lesson card
  • Consistent spacing on all elements
  • Universal box-sizing reset
┌──────────────────────────┐ │ Margin │ │ ┌────────────────────┐ │ │ │ Border │ │ │ │ ┌──────────────┐ │ │ │ │ │ Padding │ │ │ │ │ │ ┌──────────┐ │ │ │ │ │ │ │ Content │ │ │ │ │ │ │ └──────────┘ │ │ │ │ │ └──────────────┘ │ │ │ └────────────────────┘ │ └──────────────────────────┘
/* Universal reset — always use this */

Phase10
Learn Responsive CSS
@media queries, max-width/min-width — make the entire app work on every device.
Responsive
Learn
  • @media — breakpoint declarations
  • max-width: 768px (tablet)
  • max-width: 480px (mobile)
  • min-width (mobile-first approach)
  • Fluid: %, vw, vh, rem
Build
  • Desktop: 3-column course grid
  • Tablet: 2-column layout
  • Mobile: single column stack
  • Hamburger menu on small screens
.course-grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
}
@media (max-width: 768px) {
    .course-grid {
        grid-template-columns: 1fr;
    }
}
Phase11
Style Forms — Student Registration
Input, textarea, select, button — :focus and :hover states for a polished registration UI.
Forms
Learn

  • :focus — focus ring / outline
  • :hover — hover feedback
  • placeholder color
  • button states: default, hover, active
Build
  • Name, Email input fields
  • Choose Course dropdown
  • Learning Goal textarea
  • [ Create Profile ] submit button
input, textarea, select {
    width: 100%;
    padding: 12px;
    border: 1px solid #cbd5e1;
    border-radius: 8px;
}
input:focus {
    outline: 2px solid var(--primary);
}

Build

Phase15
Transitions & Animations
Subtle, purposeful motion — hover lifts, smooth state changes, gentle progress updates.
Interaction
Learn
  • transition: property duration easing
  • transform: translateY, scale, rotate
  • animation: name duration iteration
  • @keyframes — define animation steps
Apply To
  • Course cards — subtle hover lift
  • Buttons — smooth background shift
  • Quiz answers — state transition
  • Progress bars — animated fill
  • Notifications — gentle appearance
.course-card {
    transition: transform 0.2s ease;
}
.course-card:hover {
    transform: translateY(-4px);
}
Phase16
Create Dark Mode
Two themes from one codebase using CSS variables — switched by JavaScript toggling a data attribute.
Theming
Light Mode
  • --background: #f8fafc
  • --surface: #ffffff
  • --text: #1e293b
  • Bright, readable, welcoming
Dark Mode
  • --background: #0f172a
  • --surface: #1e293b
  • --text: #f8fafc
  • Easy on eyes, night learning
[data-theme="dark"] {
    --background: #0f172a;
    --surface:    #1e293b;
    --text:       #f8fafc;
}
/* JavaScript switches via: */
/* document.body.dataset.theme = 'dark' */
Phase17
Accessibility-Oriented CSS
Contrast, focus rings, motion preferences — every learner can use the app.
Accessibility
Focus On
  • Readable text (16px+ body)
  • Colour contrast ≥ 4.5:1 ratio
  • Visible keyboard :focus-visible
  • Sufficient clickable areas ≥ 44px
  • prefers-reduced-motion
Build
  • Focus rings on all interactive items
  • Skip-to-content link
  • Motion-safe animation wrapper
  • High-contrast mode support
button:focus-visible,
a:focus-visible {
    outline: 3px solid currentColor;
    outline-offset: 3px;
}
@media (prefers-reduced-motion: reduce) {
    * { transition: none !important; }
}
Phase18
Build a Reusable Design System
Organize CSS professionally — colors, typography, spacing, buttons, cards, forms, navigation.
Design System
System Includes
  • Color tokens (--primary, --text…)
  • Typography scale (--text-sm to --text-xl)
  • Spacing scale (--space-1 to --space-5)
  • Button variants (primary, ghost, outline)
  • Card, form, nav, alert components
Think Like
  • A UI system designer
  • Style components, not pages
  • One change → whole app updates
  • Consistent spacing everywhere
:root {
    --space-1: 4px;
    --space-2: 8px;
    --space-3: 16px;
    --space-4: 24px;
    --space-5: 32px;
}

The Core Learning Cycle

How to Learn Every Phase

Apply this cycle to every single phase — it builds deep understanding through doing, not just reading.

📖
Learn
Read the concept — understand the CSS property and what it controls.
💻
Code
Write the CSS rule in your style.css file against real HTML.
🧩
Build
Apply the concept to a real component of the Smart Education App.
🔍
Test
Open in browser. Check desktop, tablet, and mobile views.
🐞
Debug
Use browser DevTools to inspect elements and fix issues.
🚀
Improve
Refine the design, add a transition, check responsiveness, then move on.

Final Philosophy

Don't learn CSS by memorizing properties. Learn it by designing a real app — one component at a time, with intention.
